# 品类实战案例集：跨站点与淡旺季

> 公开通用版：仅保留可复用的方法，不含客户身份、账户表现、内部阈值或操作话术。

## 适用目标

帮助在不同站点和季节性周期中组织类目推广思路。

## 建议流程

1. 记录各站点的需求、价格、语言和物流差异。
2. 将旺季准备拆成库存、商品页、预算、素材和监控事项。
3. 用相同定义比较季节变化，单独标记促销与供给影响。
4. 复盘可迁移的原则，同时保留站点差异。

## 复核要点

- 不要把一个市场的经验直接套用到另一个市场。
- 季节性预测应定期更新。
