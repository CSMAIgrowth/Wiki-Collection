# 案例：商品重塑广告结构从 0 到 1 全流程

> 公开通用版：仅保留可复用的方法，不含客户身份、账户表现、内部阈值或操作话术。

## 适用目标

展示商品定位变化时如何同步调整广告结构与衡量方式。

## 建议流程

1. 明确重塑目标、受众变化和商品信息更新范围。
2. 清理与新定位不匹配的搜索流量，再建立结构化测试。
3. 按意图分组观察流量质量和商品页承接效果。
4. 依据测试证据扩大覆盖并记录未解决风险。

## 复核要点

- 结构迁移应分阶段进行，保留比较基线。
- 不要将同期促销或价格变化归因于结构调整。
