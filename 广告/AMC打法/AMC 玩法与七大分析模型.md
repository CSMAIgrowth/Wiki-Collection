# AMC 玩法与七大分析模型

> 公开通用版：仅保留可复用的方法，不含客户身份、账户表现、内部阈值或操作话术。

## 适用目标

以零售媒体受众与购买路径分析支持营销规划。先明确业务问题，再选择适配的分析视角。

## 建议流程

1. 将问题拆成受众覆盖、购买路径、触点关系、商品关联、品牌新客和时间行为等方面。
2. 每次分析只回答一个主要问题；统一人群定义、归因窗口和排除条件。
3. 用可复核的查询逻辑对样本做质量检查，输出趋势和限制。
4. 将发现转成小范围试验，并预先设定观察指标。

## 复核要点

- 不同分析视角依赖不同的事件定义和数据覆盖。
- 归因关联不能直接证明增量因果。
