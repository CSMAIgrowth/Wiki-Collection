# 自定义词库使用技巧：轻松管理关键词

用 SparkX 自定义词库井然有序管理关键词的几种构建技巧。

## 场景 1：构建高效备用词库

某 ASIN 的 campaign 否定/暂停关键词后，从备用词库快速补充，维持流量稳定。
Step1 建「ASIN1_备用词库」→ Step2 从关键词推荐/搜索词等筛选潜力未投放词（如 ABA 趋势上升的高相关词、TOP3 点击转化集中度低的词）移入 → Step3 一键投放。

## 场景 2：已投放关键词策略调整与批量管理

- 联动店铺数据（产品线/父 ASIN/ASIN 多维度筛选），监控 ACoS、CVR、CPC 及环比。
- 策略调整：表现好的移入高效词库，表现差的调整或否定。
- 批量管理：批量把「高效词」挪到「低效词」、从原词库删除、批量添加否定投放。

## 场景 3：否定词库（垂直类目卖家多用）

批量否定 ASIN/父 ASIN/品线的低效/无效关键词。下载词库报表 → 按「已否定投放广告数」降序找高频否定词 → 建否定词库 → 批量添加否定投放（选精准/词组匹配）。

## 场景 4：按流量分类

按流量大小分「大流量词 / 中等流量词 / 长尾词」，避免高流量词独占预算、低曝光词默默无闻。参照 ABA 搜索排名、第三方插件判断流量大小。

## 场景 5：按效果分类

按表现分「高效词 / 潜力词 / 低效词 / 无效词」，避免低效无效词抢占预算、高效词无预算可花。

## 2026-10-24 增补：帮助中心《词库：从基础管理到自动分类》口径（合集第二次抓取）

上文五个场景为"运营必看"版本；以下为帮助中心功能文档的补充口径。

### 两种词库类型

- **普通词库**：基础管理、基于商品关联的数据分析、跨店铺共享。
- **规则词库**：在普通词库上增加自动化分类与动态更新，实现精细化管理。创建需指定：关键词来源（至少一项）、数据周期、广告来源、执行时间；可设置**循环执行**让系统自动更新词库。
- 创建必填：词库名称、区域、店铺、权限类型；可选：关联商品、添加关键词。

### 自动分类规则（场景 4/5 的官方阈值）

按表现分类判断条件：高效 = 高花费+低 ACoS；潜力 = 低花费+低 ACoS；低效 = 高花费+高 ACoS；无效 = 高花费+无转化。

按 ABA 排名分类流量层级：热门流量词 < 10000；流量大词 1w-5w；中等流量词 5w-20w；长尾词 20w-100w。

按词根自动分类：核心词（pot/pan/skillet/wok）、特征词（nonstick/stainless/heavy-duty）、受众词（chef/home cook/beginner）、场景词（camping/indoor/BBQ）、配件词（lid/handle/cover）、属性词（silver/red/blue）、品牌词、竞品词。

### 操作与硬限制

- 编辑、复制、删除词库；导入关键词**每个词库上限 5000 个**，超限系统按优先级规则截取；合并词库、批量关联商品。
- 权限类型：公开只读 / 公开协作 / 私密；支持规则覆盖、词库管理权转让。
- ABA 排名每周更新，有 3-4 天延迟；仅已投放并产生数据的关键词显示表现数据。
- 已绑定应用场景的词库需先解除绑定才能删除。

### ABA 数据指标口径

- 点击集中度：排名前 3 位 ASIN 的点击份额之和。
- 转化集中度：排名前 3 位 ASIN 的转化份额之和。
- 机会系数：转化集中度 ÷ 点击集中度，**接近 1 表示市场未被垄断**。
