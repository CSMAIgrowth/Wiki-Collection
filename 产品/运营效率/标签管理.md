# 标签管理

将广告活动、商品（ASIN）和关键词按业务维度统一归类，实现跨模块筛选与批量管理。

## 三类标签对象及关注维度

| 对象 | 关注维度 |
|------|---------|
| 广告活动 | 产品线、投放意图、广告结构策略 |
| 商品（ASIN） | 商品分类、生命周期、库存状态、竞品管理 |
| 关键词 | 品牌/非品牌、相关性、匹配方式、否词策略 |

## 结构与规则

- **跨店可见与数据隔离**：标签仅在其关联店铺下可见；广告活动关联受账号权限限制。
- **父子层级**：支持 1-2 级；两种用法（父子层级 vs 平级分组）不能混用。
- **三种标签类型**：

| 对比项 | 手动标签(手动关联) | 手动标签(规则关联) | 自动标签 |
|--------|-------------------|-------------------|---------|
| 核心用途 | 灵活打标，人工增删 | 按定义条件自动归类 | 按命名规范自动生成 |
| 适用对象 | 广告活动/商品/关键词 | 广告活动/商品/关键词 | 仅广告活动 |
| 需配置规则 | 否 | 是 | 是 |

- **权限**：公开协作（默认，全员可编辑）/ 公开只读（仅管理员和主账号可编辑）/ 私密（仅管理员和主账号可见可编辑）。

## 标签体系规划指南

- **广告活动标签**：产品线（产品A/B/C）、投放意图（拓新/收割/品牌防御）、定向类型（自动/手动关键词）、表现状态（ACOS偏高/待优化）、时间节点（Q1/Q4/旺季/大促）。
- **商品标签**：本品管理（属性、推广程度、生命周期、库存状态）；竞品管理（竞品调研、定向策略、否定商品）。
- **关键词标签**：品牌/非品牌、广告表现/流量质量、相关性分级、否词管理、词义主题/场景。

## 创建方式

1. **手动标签**：自定义分组，手动圈选对象。
2. **自动标签**：按广告活动名称中的分隔符拆解字段，将指定位置字段值自动生成子标签；要求命名有统一分隔符和固定字段位次。
3. **批量导入**：支持 .xlsx/.xls，单文件 ≤20MB、≤3 万行。

## 跨模块应用

- **通过标签筛选**：全部搜索广告 / 全部商品列表 / 关键词 / 自定义看板 / 自动化规则 / 智能中心 / 首页 / 通用选择器。
- **添加到标签**：在全部搜索广告、关键词推荐、竞品推荐、智能创建等页面勾选对象后批量打标。
- **从标签添加**：智能创建和词库导入时可直接引用标签内对象。

## FAQ（排查清单）

- 搜不到标签 → 检查店铺筛选器（标签仅关联店铺可见）。
- 关联数量不一致 → 受账号权限控制。
- 删除标签 → 不影响广告投放状态和历史数据。
- 操作按钮灰色 → 当前账号无编辑权限。
