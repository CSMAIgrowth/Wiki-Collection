# 排名监控

针对单个或多个关键词，在店铺商品与竞品层面监控广告排名与自然排名，区分并追踪广告流量与自然流量排名变化。

## 使用条件

- 开放站点（10 个）：美国、墨西哥、加拿大、日本、澳大利亚、英国、法国、德国、西班牙、意大利（无巴西、印度，与关键词推荐开放范围不同）。
- 数据口径：系统旨在反映排名**趋势变化**，非逐次精确抓拍。

## 操作路径

1. 【排名监控】→【添加监控任务】。
2. 输入任务名称 → 选择站点 → 添加商品 ASIN → 添加竞品及关键词。
3. 创建后即可查看本品及竞品的自然排名、广告排名表现。

## 任务详情

- **监控对象**：本品及竞品的广告排名、自然排名；可选择是否展示变体排名。
- **排名趋势**：自然排名、广告排名、价格、星级评分、评分数。
- **批量操作**：对监控对象支持添加投放、否定投放、删除。

## FAQ（排查清单）

| 现象 | 原因 |
|------|------|
| 排名显示为"-" | 任务添加不满 1 日，或商品未进入搜索结果前 3 页 |
| 历史数据为空 | 新添加的竞品/关键词无法回溯历史 |
| 排名数值有出入 | 系统口径为趋势变化，非实时精确值 |
