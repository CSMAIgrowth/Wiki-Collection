# 筛选条件 + 批量操作：告别广告优化繁琐操作

用 SparkX 广告管理的「筛选条件 + 批量操作」组合，快速完成日常广告优化。以**降 ACoS** 为例：

## 调整思路

- 目标：降 ACoS
- 重点：调整幅度和订单量
- 操作：高花费无转化搜索词否定 + 高 ACoS 词降竞价
- 目的：不影响销售额的情况下 ACoS 下降

## 操作方法

1. **加入否定，排除无效流量**：设条件（如 花费>30 且 订单数=0）筛选无效流量 → 保存条件组「高花费无转化」→ 批量否定。
2. **高 ACoS 定向降竞价**：设条件（如 花费>30 且 ACoS>50%）筛选高 ACoS 词 → 保存条件组「高花费高ACoS」→ 按固定值/比例批量降竞价。

保存的条件组后续可持续复用，实现一键筛选切换。
