# 如何提升多变体产品的管理效率

用商品中心管理多变体商品，清晰列举不同变体的总销售与广告表现。

## 操作

1. 搜索框输入父 ASIN，查看该父 ASIN 下不同子 ASIN 的表现。
2. 选时间段，按不同指标排序，快速定位子体表现，重新分配预算、提高花费效率。

## 建议优化方式（按 TACOS + 广告订单/花费）

- **主力 ASIN**：广告订单多且 TACOS 低 → 加大广告投入。
- **潜力 ASIN**：广告花费低且 TACOS 低 → 加大广告投入。
- **低效 ASIN**：广告花费高且 TACOS 高 → 减少广告花费。
- **无效 ASIN**：过去一段时间有一定花费但无转化 → 暂停投放。
