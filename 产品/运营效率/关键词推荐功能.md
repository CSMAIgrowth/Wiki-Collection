# 关键词推荐：七大关键词来源与店铺数据联动

输入产品 ASIN 即可联动七大关键词来源与自身店铺数据，简化关键词收集。

## 四大能力

1. **一站式关键词推荐**：输入 ASIN，获取七种不同数据源的关键词推荐。
2. **广告投放状态可视化**：展示每个关键词在不同广告类型的已投放广告数，突出未投放的推荐词，便于快速决策。
3. **联动自定义词库**：一键将推荐词加入自定义词库，为后续策略/定向规划做准备。
4. **关键词指标一览**：即时展示 ABA 排名、点击与转化集中度汇总、广告历史表现，联动店铺数据分析流量大小、市场垄断性和潜在价值。

以下为 SparkX 帮助中心「效率工具」合集内《关键词推荐》文章的操作细节，与上文"运营必看"版本互补。

### 使用条件（硬指标）

- 开放站点（12 个）：美国、墨西哥、加拿大、巴西、日本、澳大利亚、英国、法国、德国、西班牙、意大利、印度。
- 支持数据展示的广告类型：SP、SB。
- 数据同步：关键词推荐按 ABA 排名周期获取（每周），**数据更新有 3-4 天延迟**。

### 操作路径

- 先在页面选择商品后查看；支持多商品选择（浏览器记忆）；多 ASIN / 父 ASIN / 产品线选择时展示各 ASIN 推荐词**并集**。
- 关键词来源七类：历史高转化词（过去 30 天较高出单）、品类词、竞品高频词、ABA 搜索词（搜索排名靠前且 TOP3 ASIN 点击转化份额不高）、亚马逊推荐词、词根拓词（AI 词根排列组合）、品牌词。
- 页面组成：ASIN 筛选、ABA 排名分布图表（峰值）、关键词表格（ABA 数据 + 广告效果数据）。
- 支持操作：添加投放（选匹配类型、出价、广告组）、否定投放（选否定匹配类型、广告活动）、关联标签、创建广告组/广告活动（新增功能）、添加到词库（已有或新建词库）；支持批量添加到多个广告。

### FAQ（排查清单）

- 某来源无数据 → 依赖 ASIN 的其他数据，并非所有来源都有推荐。
- ABA 排名图表日期选择无效 → ABA 为固定周期数据，日期仅作用于广告效果指标。
- 部分关键词无 ABA 历史趋势 → 新词无历史数据。
- 部分关键词无效果数据 → 仅已投放的词展示效果。
