# Insight Agent 使用指南（公开版）

Insight Agent 类工具可通过自然语言帮助用户探索广告数据、发现趋势和形成分析草稿。使用者应提供明确问题、对象范围、时间窗口和需要的输出形式。

## 建议提问结构

- 业务问题：想解释或比较什么？
- 范围：站点、商品、广告类型和时间窗口。
- 指标：使用的口径与排序方式。
- 输出：结论、证据、限制和建议的下一步。

## 核验结果

核对数据范围、过滤条件和计算口径；重要结论回到明细复算。将相关性与因果解释分开。若数据覆盖不足，应明确标示。

## 使用边界

AI 输出是分析辅助，不替代业务审批。避免输入凭据、个人信息或未经授权的客户资料。

## 来源

依据产品功能主题整理为公开指南；功能范围和可用状态以当前官方文档为准。
