# Reporting Agent 使用指南（公开版）

## 适用任务

报告类助手可用于汇总指定范围的数据、组织图表和生成说明草稿。任务开始前需确认数据源、时间范围、指标定义和报告受众。

## 操作流程

1. 选择合规的数据范围和报告主题。
2. 检查指标、维度和比较窗口。
3. 生成草稿后核对图表、单位、日期和过滤条件。
4. 标注无法从数据直接证明的解释。
5. 经负责人审核后再分享或导出。

## 数据与权限

遵守账户权限与数据最小化原则。不要上传账号凭据或个人信息；共享前检查报告中是否包含不应外发的客户明细。

## 来源

依据产品说明主题整理为公开流程；可用状态和安全控制以当前官方文档为准。
