# 竞品推荐

基于商品进行搜索词、商品详情页、BSR 榜单等多来源的竞品推荐，加强对商品主要竞品的认知；可对重点竞品做商品定向投放，或对低效定向否定定向。

## 使用条件

- 支持站点（11 个）：美国、墨西哥、加拿大、巴西、日本、澳大利亚、英国、法国、德国、西班牙、意大利。
- 需授权 SP-API 后在商品中心查看；数据每日计算更新，**首次授权后 2-7 日可查看**。

## 推荐逻辑

按同一父 ASIN 下选择最主要售卖的 ASIN 作为推荐基础，结合品类、商品价格及评分数等信息，从多种来源获取推荐竞品。**推荐指数越高代表 SparkX 越推荐对该商品做定向投放**。

## 五种竞品来源

| 来源 | 逻辑 |
|------|------|
| 关键词搜索 | 根据商品近期投放 SP 的出单搜索词，取最能代表商品的 3 个核心关键词 |
| 品类词搜索 | 按当前商品所属品类词获取竞品 |
| 商品详情页 | 当前 ASIN 在亚马逊详情页中展示的商品 |
| 亚马逊热卖榜 | BSR 榜单中与当前商品相似的商品 |
| 亚马逊新品榜 | 新品榜中与当前商品相似的商品 |

## 竞品信息与应用

- 可按**数据来源**和**商品分类（同品类/其他品类）**筛选。
- 针对同品类商品：展示竞品的品牌、价格、星级评分、评分数的**分布分析图表**。
- 支持操作：添加商品定向、否定定向、打标签。

## FAQ（排查清单）

- 看不到数据 → SP-API 授权后需等 2-7 日；或该 ASIN 近期无 SP 投放数据。
- 商品存在多个品类时 → 查看"其他品类竞品"中是否有数据。
