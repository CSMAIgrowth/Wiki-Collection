# 自定义报告

跨店铺、跨广告活动类型的自定义数据下载中心，支持自定义店铺范围、数据指标范围，并支持周期性推送报告。

## 使用条件（硬指标）

- 站点限制：无；广告活动类型限制：无。
- **每个用户同时开启上限：10 份报告模版**。
- 支持的报告类型（9 类）：店铺、广告活动、广告位、搜索词、匹配的投放报告、定向、推广商品、标签、商品中心报告（Seller、Vendor）。
- **单次报告数据量超过 30 万条时发送失败** → 可按店铺拆分或增加筛选条件。

## 使用流程

创建报告 → 选择报表类型 → 设置报告 → 接受推送/下载 → 管理报告。

## 报告创建设置项

| 设置项 | 说明 |
|--------|------|
| 店铺范围 | 一次最多选 200 个店铺 |
| 日期范围 | 本周/上周/本月/上月/最近 X 天/自定义 |
| 广告活动类型 | 随报告类型变化 |
| 自定义筛选 | 每种报告类型均支持本层级及以上层级筛选 |
| 货币 | 美元/本币 |
| 时间细分 | 按日期范围、日、周、月、季度、年汇总 |
| 自定义列 | 维度、指标、数据对比 |
| 推送模式 | 下载格式（xlsx/csv）、文件拆分方式、推送周期、报告发送方式 |

Vendor 报告注意：**数据选择时间默认排除近 4 日**。

## 报告管理

- 批量操作：开启、暂停、删除、修改日期范围、推送周期、推送邮箱。
- 可编辑报告、查看历史推送记录、复制报告模版。
- 权限：主账号可见子账号报告，但**不可编辑、删除**。
