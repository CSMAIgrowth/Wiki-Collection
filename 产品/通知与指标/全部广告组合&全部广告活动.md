# 全部广告组合&全部广告活动

SparkX 广告管理模块承接亚马逊基础广告管理并做效率增强：跨店铺、跨广告活动类型的聚合管理界面，支持新建、筛选、批量操作、可视化图表与 AI/自动化工具快捷入口。

## 使用条件与入口

- 需授权 ads-API 后方可使用。
- 入口：【广告管理】-【全部广告组合】、【全部搜索广告】。

## 全部广告组合

- 筛选：可按条件及 ASIN 筛选广告组合。
- 数据图表：数据趋势、广告结构、散点透视三类视图。
- 新建广告组合：填写信息即可创建。
- 批量操作：批量调整广告组合预算（仅相同站点时可用）。
- 点击组合名进入详情；点击广告活动数量跳转查看该组合下全部广告活动。

## 全部搜索广告（分层管理）

| 层级 | 可执行操作 |
|------|-----------|
| 广告活动 | 筛选（可按 ASIN）、三类图表、新建、批量操作 |
| 广告组 | 批量启用、暂停、存档、打标签 |
| 投放-关键词 | 批量修改状态、竞价、打标签；汇总视图查看多店铺汇总并下钻细分记录 |
| 投放-商品投放 | 批量修改投放状态、竞价、打标签；汇总视图下钻 |
| 否定词 | 添加否定词（选否定方式+目标广告活动）；批量启用/暂停/存档/复制/打标签；批量复制到其他广告活动或广告组 |
| 推广商品 | 添加推广商品（只加到所选店铺的目标广告组，跨店铺提交时商品与广告活动须同店铺）；批量启用/暂停/存档/打标签；汇总下钻 |
| 搜索词 | 批量添加投放、添加否定投放、打标签、快捷查看 |

## 搜索词批量添加投放的关键规则

- 对象：关键词和 ASIN 类型搜索词可同时添加。
- 添加到：来源广告组（搜索词来源组）或目标广告组（任意符合条件的组），也可新建广告活动/广告组。
- 可统一设置竞价与匹配类型，点击应用后应用到投放列表。
- 快捷过滤项：一键过滤已添加投放的搜索词；去除非法字符；一键过滤预算不足广告活动——**预算活跃时间均值 < 100 的广告活动被过滤（空值不过滤）**。
- 批量添加否定投放：同样支持来源/目标广告组，可设否定匹配类型，支持过滤已添加否定投放的搜索词。
