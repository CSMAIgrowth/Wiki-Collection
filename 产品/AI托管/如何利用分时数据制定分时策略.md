# 如何利用分时数据制定分时策略

核心思路：核心时段重点投放，低效时段减少花费。用小时级数据驱动「分时预算」和「分时调价」。

## 参考数据 1：店铺分时出单 + 周天分析

适合全店垂直类目、人群精准的店铺。用店铺维度分时出单数据 + 周天分析判断主要出单时间，配合分时调价/分时预算做预算管理。入口：首页看板 → 选店铺 → 销售看板。

## 参考数据 2：广告管理 AMS 数据

快速筛选父 ASIN / ASIN / SKU / 广告组合 / 广告活动，用 AMS 深入分析；回顾至少一个月销售小时数据，辨明高峰低谷，依据花费、订单量理解消费习惯。高效时段加预算/提竞价，低效时段减预算/降竞价。

## 分时预算设置

工具 → 自动化规则 → 新建「分时预算」模板 → 选中降低日预算的时间段 → 选预算分配规则 → 关联具有一致转化时间分布规律的广告活动。

## 分时调价设置

工具 → 自动化规则 → 新建「分时调价」模板，两种方式：
1. 选时间点 + 执行天 + 竞价倍数；
2. 拖拽表格对应天/时间点，填出价系数。
