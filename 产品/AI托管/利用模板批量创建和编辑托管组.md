# 利用模板批量创建和编辑托管组

通过 Excel 一次性完成多个 AI 托管组的创建或配置更新。批量创建与批量编辑是**两个独立入口、两套模板**，必填字段和留空语义不同。

## 批量创建托管组

下载入口：AI托管页面→Smart creation/智能创建下拉→批量创建托管组。模板含「申请表」（系统按**工作表名称**识别：中文"申请表"/英文 Application Form/日文"申請フォーム"，不依赖位置）和「填写说明」两张表；标准字段名称、顺序、值格式必须保留，说明表可删改。

必填字段：托管组AI开启状态；托管组名称（**≤200 字符**）；Profile ID；广告活动类型（SP/SB/SD，同一托管组内必须一致）；Campaign ID list（半角逗号分隔，表示新托管组**最终完整** Campaign 集合）；目标ACoS/RoAS + 目标值（不带百分号，如 15% 填 15）；托管目标（推动增长/活动冲量/保持订单稳定）；AI人格（1–5）；Campaign name tag status（Y/N）。

选填字段：Managed Group Budget（留空=按当前已启用 Campaign 日预算总和补齐；填值=按日预算比例重新分配）；行动空间开关（Y 开/N 关/**留空按关闭**，创建场景开启的行动空间默认 AI 优化方式）；ACOS优先模式（填 Y 但暂不满足生效条件时创建仍成功、暂不生效）；Bid Range Type（VALUE/COEFFICIENT/CLEAR）+ Bid Range Value（CLEAR 时必须留空，两者均空=不设置）。

上传约束：.xlsx/.xls，**≤10MB**；单次最多 **700 个托管组**；单个托管组**整体成功或整体失败**（任一字段或 Campaign 校验失败则整组不写入）；任务级允许部分成功。Campaign 已属其他托管组时校验通过后**自动迁移**；同一文件中同一 Campaign 写入多个目标托管组则相关托管组失败。

## 批量编辑托管组

- 先筛选目标托管组，确认 **≤700 个**；预填充编辑模板包含当前筛选范围的全部匹配（不跟随手动勾选行），超过 700 不允许下载、不自动截取。
- 模板二选一：**空白编辑模板**（已知目标：手填 Profile ID + Managed Group ID + 待编辑字段）/**预填充编辑模板**（先看当前设置再改；需开通权限；自动带入 ID 与当前设置，可选是否含托管组级广告表现数据——表现列仅供参考，上传时自动忽略）。
- 定位字段：Profile ID + Managed Group ID，无法定位唯一托管组则该行失败。
- **局部覆盖语义**：填值的字段参与编辑，留空不覆盖原值。目标ACoS/RoAS 两字段必须同时填，只填一个则失败；Campaign ID list 留空=不编辑集合（不清空）；行动空间只改开关、不改优化方式和规则内容（原方式为规则时，关再开仍沿用原规则）；AI Status disabled 的托管组也可编辑。
- 旧版 Bid Range 合并字段与新模板**不兼容**，必须重新下载最新模板。

## 任务进度与结果

运行中任务入口仅展示**本人发起的未完成任务**，显示任务类型、文件名、状态、总托管组数、已处理数。完成后从运行中移除，站内信查看结果：总数/成功数/失败数、每托管组状态、失败原因摘要；状态分全部成功/部分成功/全部失败；首版不支持下载失败明细 Excel。
