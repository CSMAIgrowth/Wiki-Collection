# 预算管理：及时跟踪花费进度，管控预算

预算管理用于统一管理预算、跟踪花费进度、按月控制预算节奏：规划整月预算、观察消耗进度、大促/活动日设特殊预算、系统自动调整后续日期节奏、在一组广告活动或托管组间统一分配预算、把分月/分日分配比例存为模板复用。

入口：**高阶广告设置 → 预算管理**。预算组分两种：**广告活动级别**（管理一组具体广告活动/托管组）与**店铺级别**（整店维度）；同一店铺下两者**不能同时开启**。

## 进度指标（两级同口径）

- **Budget left**（剩余预算）：月预算 − 当月累计花费，**可为负**（花超）。
- **Budget left %**：Budget left ÷ 月预算。
- **Days left %**：当月剩余天数 ÷ 当月总天数（剩余天数含当天）。
- **Delivery rate**（执行率）：桶内花费 ÷ 桶内预算 ÷ 桶内时间进度；已结束的日/周/月时间进度记为 1，当前周/月按已过天数计。触发过日度超支停止的那天照常计算（该日 Delivery rate 偏高，正说明花到上限才暂停）。

## 趋势图表与每日明细

图表提供 Spend、Planned budget、Delivery rate、Sales、ROAS 五指标，月/周/日三档粒度 + 起止月选择，可导出 Excel。未勾选时展示全部预算组汇总；勾选后需点「N 已选中：查看趋势」才聚合所选组。**比值型指标（Delivery rate、ROAS）先聚合分子分母再计算，不做简单平均**；只选单月时默认切日粒度。每日明细入口可看月度指标卡片、Daily budget 与 Spend 折线对比、每日趋势表格，超支停止日期有图标标记，支持导出。

## 列表修改规则

- **数值类**可在列表直接改：组预算、组内占比与金额、Target ROAS、Min ROAS 护栏；三个入口（组预算/子行占比/子行金额）进入同一整组编辑态，改动后其余行**自动配平，合计恒为 100%**。
- **开关类**需进编辑页或批量操作；列表上仅"自动预算节奏控制"可直接切换，其余开关只回显状态。

## 广告活动级别预算组（5 项配置）

1. **月预算**：控制当月整体花费上限；开启安排每日预算或 Auto pacing 时，系统结合已花费与剩余天数计算后续每日预算。
2. **安排每日预算**：手动设置的日期按设置执行，其余日期自动分配；系统**每日 0 点执行一次分配**。
3. **按 % 分配组内预算**：控制组内各 campaign/托管组的预算份额。
4. **自动预算节奏控制（Auto pacing）**：按消耗进度与表现动态优化当日预算分配。
5. **Min ROAS 护栏**（需配合 AI 托管）：Auto pacing 尽量花完预算的同时守住 ROAS 底线。

## 分配模板与店铺级别

- 分配模板两种：**分月模板**（全年 12 个月各自占比）、**分日模板**（某年某月每天的占比），可应用到多个预算组。
- 店铺级别两种方式：**仅监控模式**（只看整店进度不改广告预算）/ **动态分配模式**（系统结合当月历史花费动态分配店铺剩余预算）。

## 场景速查

只想看进度 → 关闭开关或仅监控；有大促日 → 活动级别+安排每日预算；不想手动调 → Auto pacing；又要花完又要守 ROAS → Min ROAS 护栏。

## 版本升级记录（2026-10-24 并入，原独立页《预算管理升级指南》）

预算管理功能升级说明，原文发布日期 **2026-03-10**。核心变更：从 3 个模式改为 3 个开关。

### 升级前：3 个模式

- 仅监控（Monitor Only）
- 固定分配（Fixed Allocation）
- 动态分配（Dynamic Allocation）

### 升级后：3 个开关

- **安排每日预算**（Daily scheduling）
- **活动分配**（Campaign Allocation）
- **AI 自动预算节奏控制**（Auto pacing，**新增**）

### 推荐配置（口径）

| 需求 | 配置 |
|------|------|
| 只想查看可见性 | 关闭全部开关 |
| 有固定计划，强制执行分配比例 | 开启活动分配 |
| 有大促日期 | 开启安排每日预算 |
| 第一目标是按计划花完月预算 | 开启自动预算节奏控制 |

升级后的开关体系即本页上文所述现行「预算管理」的配置项（含 Min ROAS 护栏、分配模板、店铺级预算组等升级后能力）。原文为简短升级公告，模式 → 开关的完整字段映射需回原渠道补采 [待核实]。
